# faheem-media

Finished Faheem videos, hosted here only so Metricool can fetch them for scheduling.

- One folder per week: `W47/`, `W48/`, …
- File name = the post id, e.g. `W47-sat-1.mp4`, plus its cover `W47-sat-1-cover.png`.
- Only videos Khaloud has approved on the crew's live page are added.
- Public by design: the files are the same cartoon videos that get posted. No children's data, no personal data.
